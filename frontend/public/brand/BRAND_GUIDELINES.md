# Concerto Brand Guidelines

## Logomark

The Concerto mark is three concentric orbital arcs with staggered gaps, each carrying a small
agent dot. A cream hub dot at center represents the operator/conductor.

### Files

| File | Use |
|------|-----|
| `logomark.svg` | Default mark, dark backgrounds |
| `logomark-dark.svg` | Identical to logomark.svg, explicit dark variant |
| `logomark-light.svg` | For light/white backgrounds |
| `wordmark.svg` | Mark + "Concerto" text, horizontal, dark bg |
| `wordmark-light.svg` | Horizontal wordmark for light backgrounds |
| `wordmark-stacked.svg` | Mark above wordmark, vertical, dark bg |
| `favicon.svg` | Simplified 2-arc version for 16–32px |

| Token | Hex | Use |
|-------|-----|-----|
| `--accent-warm` | `#d97757` | Primary CTA, inner arc, peach/coral |

---

## Typography

- **Display / wordmark**: Fraunces (Google Fonts), weight 600, tracking −0.02em on large sizes
- **Body**: Inter, 17–18px base, weight 400–500
- **Code**: JetBrains Mono

---

## Spacing and sizing

### Minimum sizes

| Context | Minimum |
|---------|---------|
| Logomark alone | 24×24px |
| Wordmark (horizontal) | 120px wide |
| Favicon | 16×16px (use `favicon.svg` simplified version) |

### Clear space
Maintain clear space of at least **0.5× the mark height** on all sides of the mark or wordmark.

### Proportions
Do not alter the arc proportions, gap positions, or dot placement. Scale uniformly only.

---

## Do / Don't

| Do | Don't |
|----|-------|
| Use on dark (#0f0d10) or light (#faf8f5) backgrounds | Place on busy, saturated, or mid-tone backgrounds |
| Use `logomark-light.svg` on white/cream backgrounds | Use the dark-bg version on white (insufficient contrast) |
| Scale uniformly | Stretch or skew the mark |
| Maintain arm's-length from Anthropic logo composition | Use evenly spaced 120° arc gaps (that's Anthropic's proportion territory) |
| Use peach for primary CTA buttons | Use the violet alone as the primary brand color |

---

## Brand voice

Restrained, editorial, warm. Concerto is a tool for serious builders — the brand should feel like
a well-designed developer notebook, not a consumer app. Serif display type, generous whitespace,
slow dignified motion.
