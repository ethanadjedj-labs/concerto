5 things power users do with Concerto.

Three weeks in, here's what we see from operators who get the most out of their Droplet:

01
Overnight dependency upgrades
Run npm audit fix --force across 6 repos simultaneously, each in its own tmux session. Claude Code opens PRs, runs tests, and flags breakage. Wake up to a diff review, not a task list.
02
Persistent scraping pipelines
Set up a Python scraper on the Droplet, have Claude Code schedule it via cron, then check results the next day. The Droplet keeps running after your claude.ai session closes — no cloud function cold starts, no timeout at 30s.
03
Multi-file refactors with full grep context
Claude Code on a real shell runs rg, find, and sed across the whole codebase — not just open files. Operators use this for API migrations where you need to touch 40+ call sites across a monorepo.
04
Local model inference via Ollama
Install Ollama on the Droplet, pull llama3:8b, and have Claude Code use it for fast local inference tasks — summarization, classification, data extraction — without API costs or rate limits.
05
Database migrations with real-time validation
Run the migration, query the result set, validate row counts, and roll back if the delta is wrong — all in one Claude Code session. Because the Droplet has network access, it can hit staging and production DBs in the same session.

Which of these fits your workflow? Reply and tell us — the best use cases make it into our docs.
