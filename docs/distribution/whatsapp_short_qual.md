# WhatsApp — Qualification rapide (identifier early adopter)

Registre : court, ouvert, zéro pression. Objectif : savoir si la personne est utilisateur actif avant d'envoyer un pitch.

---

> {first_name}, question rapide : tu utilises Claude Code ou des agents IA dans ton boulot en ce moment ? {why_them} — je construis quelque chose pour simplifier ça et je cherche les premiers testeurs. 30 secondes si t'as une seconde.

*[~250 car.]*

---

**Variables** : `{first_name}`, `{why_them}`

Exemples pour `{why_them}` :
- "T'as l'air de plus en plus dans cet univers"
- "Je t'ai vu poster des trucs sur les agents"
- "On en avait parlé vaguement"

**Lecture des réponses** :
- Signal positif → "oui j'utilise", "j'ai un Max plan", "je galère avec la config", "j'ai un VPS" → envoyer `whatsapp_direct.md` ou inviter au programme bêta
- Signal neutre → "un peu, pourquoi ?" → expliquer Maestro brièvement, demander si l'accès gratuit bêta les intéresse
- Signal négatif → "c'est quoi Claude Code ?" → éduquer d'abord, ne pas convertir maintenant
