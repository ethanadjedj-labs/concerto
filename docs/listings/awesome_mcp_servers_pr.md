Submitting Concerto for the list.

Concerto is a hosted MCP server that orchestrates Claude Code as long-lived,
remote sessions. The MCP endpoint exposes spawn/list/get/kill verbs so any
MCP-aware editor (Claude Desktop, Cursor, Zed, VS Code) can drive a fleet of
agents that survive between turns.

- Repo: https://github.com/ethanadjedj-labs/concerto
- Site: https://concerto.run
